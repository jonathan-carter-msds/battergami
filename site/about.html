About

Every MLB batter's game produces a line of ten stats — at-bats, runs, hits, doubles, triples, home runs, walks, strikeouts, RBIs, and stolen bases. Battergami watches every game and checks that line against every batting performance in MLB history, back to 1898. When a player posts a combination of those ten numbers that has never happened before — not once — the bot tweets it. It's the batter analog of pitchergami, which itself follows NFL Scorigami.

How "never happened before" is decided

Each batter-game is reduced to a ten-number vector (AB, R, H, 2B, 3B, HR, BB, SO, RBI, SB). A new game's vector is flagged only if no earlier game in the database has that exact combination. It's an anti-join, not a threshold — there's no "impressive enough" bar, just "has this precise line ever occurred." Lines with no at-bats and no walks (a pinch-runner, say) are ignored.

Data

  • Retrosheet — complete game-by-game history back to the turn of the century, used for the one-time backfill that forms the baseline.
  • MLB Stats API — official box scores within hours of a game ending, which is what lets the bot post same-day.

Both feed one table, so the check treats all of history as one continuous record. "First-ever" counts lean toward the dead-ball era on purpose: in 1898 almost every line was new, so players like Honus Wagner and Ty Cobb top the leaderboard.

This site

Static pages with no backend. A build script re-queries the database once a day and commits refreshed JSON; the whole "has this line happened" dataset is about 35,000 rows, small enough to answer every lookup in your browser. The Check a Line tool, Board, and Calendar all run off that one file.
